# HospitalityPro — VS Code Export

Esta es la versión simple y lista para Live Server.

## Abrir el sitio

1. Abre **únicamente** la carpeta `hospitalitypro-vscode-export` en VS Code.
2. Abre `index.html`.
3. Haz clic en **Go Live** o usa **Open with Live Server**.

No requiere Node, npm, terminal, instalación ni compilación.

## Archivos principales

- `index.html` — todo el contenido del sitio.
- `styles.css` — diseño y versión responsive.
- `assets/` — logotipos oficiales, fotografías de stock locales sin marca de agua y la imagen para compartir el sitio.
